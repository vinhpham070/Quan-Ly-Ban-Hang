## Features

- **Authentication & Authorization:** Secure login system with role-based access control (Admin, Cashier/Staff).
- **Product & Inventory Management:** Add, update, delete, and search products; track real-time stock levels and receive low-stock alerts.
- **Sales & Invoicing:** Fast order processing, barcode/product code lookup, discount calculation, and printable invoice generation.
- **Customer & Supplier Management:** Maintain customer profiles, purchase history, and supplier records.
- **Reporting & Analytics:** Visual dashboards and exportable reports for daily, monthly, and yearly revenue, best-selling items, and profit margins.
